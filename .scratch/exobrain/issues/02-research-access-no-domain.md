# 02 调研：无域名条件下的安全访问方案

Type: research
Status: resolved
Blocked by: 无

## Question

服务器在阿里云国内、约 2 核 4G、**没有域名、不做备案**。需要调研：从 Android 手机和 macOS 电脑上，如何安全、稳定地访问服务器上运行的外脑服务（捕获 API、问答界面、管理后台），而不把服务裸露在公网上？

候选方向至少覆盖：

1. **裸公网 IP + 端口 + 访问令牌**：直接用 `http://公网IP:端口` 访问，靠长随机令牌鉴权；风险与可接受性；
2. **Tailscale**（官方托管控制平面）：在中国大陆网络下，控制平面与中继节点（DERP）能否正常连通、直连成功率、Android/macOS 客户端体验；
3. **Headscale 自建控制平面**：Tailscale 控制平面的开源自建版，部署在服务器自身，客户端直连服务器公网 IP 组网——是否最适合无域名场景；
4. **ZeroTier**：类似方案在国内的连通性表现；
5. **SSH 隧道 / frp 类反向代理**：作为备选的可行性与日常使用成本。

产出：对比结论与**明确推荐**（含推荐理由），以及推荐方案在服务器、Android、macOS 三端的大致安装配置步骤。注意中文写作，技术缩写首次出现写全称。

## Answer

研究报告全文：[research/02-access-no-domain.md](../research/02-access-no-domain.md)

结论（供 09 决策使用）：

- **首选 Headscale 自建**：用 Docker 部署在阿里云本机，官方 Tailscale 客户端（Android/macOS）通过预认证密钥入网、指向服务器公网 IP；无需域名和备案、无设备数限制、2 核 4G 资源占用极小；业务端口只绑定虚拟网卡即不裸露公网；
- **链路天然直连**：服务器本身有公网 IP，WireGuard 直连延迟约 12–29ms，不依赖境外中继；
- **备选 A**：Tailscale 官方免费版（个人设备不限量），零运维，仅控制平面在境外有尾部风险；
- **备选 B**：SSH 密钥隧道应急；
- ZeroTier 控制器在境外且 Android 难自建 moon，不推荐；frp 对本场景多余；裸公网 HTTP 加令牌仅适合临时测试；
- 报告含三端命令级配置步骤与安全组放行清单（TCP 8080、UDP 3478/41641）。
