# 04 调研：聊天模型与嵌入模型供应商选型

Type: research
Status: resolved
Blocked by: 无

## Question

外脑的智能能力全部走云端 API（服务器无法本地跑大模型）。聊天模型用户偏好 DeepSeek，但需要核实其能力边界并选定配套的**嵌入模型**（把文字转向量、用于语义检索的模型）与可选的**重排模型**（检索后对结果重新排序以提升准确率的模型）供应商。

需要调研：

1. **DeepSeek 聊天模型**：当前提供的模型（如 deepseek-chat、deepseek-reasoner）、上下文长度、输入/输出价格（每百万 token）、从国内服务器调用的稳定性、是否提供嵌入模型；
2. **嵌入模型候选**：阿里云通义千问 text-embedding 系列（维度、价格、免费额度）、智谱/智源等国内厂商嵌入 API、在服务器本地跑小型嵌入模型（如 bge-small-zh）的内存代价；明确 DeepSeek 若无嵌入 API 时的最优搭配；
3. **重排模型**：国内可用的重排 API（如通义/智源的 rerank 服务）或本地小模型的资源占用，以及个人知识库规模下是否有必要；
4. **个人规模成本估算**：假设每月捕获 300~500 篇内容、每篇提炼一次、每天问答 10~20 次，估算月度 API 花费；
5. **接口统一性**：各供应商是否兼容 OpenAI 接口格式（便于用一个客户端库切换）。

产出：推荐的模型组合（聊天 / 嵌入 / 重排各一个，含备选）、密钥申请入口、成本估算。注意中文写作，技术缩写首次出现写全称。

## Answer

研究报告全文：[research/04-llm-embedding.md](../research/04-llm-embedding.md)

结论（供 07 决策使用）：

- **聊天直连 DeepSeek 官方**：在售 deepseek-v4-flash（约 ¥1/百万输入 token、缓存命中 ¥0.02、输出 ¥2）与 deepseek-v4-pro（¥3/¥0.025/¥6），均 100 万 token 上下文、兼容 OpenAI 格式；第三方托管（火山、SiliconFlow）更贵，仅作容灾；**DeepSeek 官方不提供嵌入与重排模型**；
- **嵌入首选阿里云百炼 text-embedding-v4**（约 ¥0.5/百万 token，与服务器同云低延迟，新用户各 100 万 token 免费）；极限省钱用 SiliconFlow 上免费的 bge-m3；
- **重排建议开启**：SiliconFlow 的 bge-reranker-v2-m3 免费，或百炼重排 ¥0.5/百万，个人规模月费约 ¥0–2.5；
- **本地跑嵌入模型不现实**：bge-m3 需 4GB 以上可用内存，2 核 4G 机器易内存溢出；
- **个人规模月度成本**：推荐组合（DeepSeek flash + 百炼嵌入 + 百炼重排）合计约 **¥8/月**；全免费向量方案约 ¥5/月；pro 高配约 ¥19/月；
- 风险：DeepSeek 已预告可能整体涨价，供应商配置应可切换；各平台注册入口与免费额度见报告。
