# MVP 验收清单与构建顺序（票据 14 工件）

2026-09-06。所有标准均从此前定稿票据推导，清单外一律推迟。

## 一、验收清单（逐条实测勾验）

**A. 访问与组网**
- [ ] A1 Mac 与 Android 均加入 headscale 网络，Tailscale 显示在线；
- [ ] A2 Mac 浏览器经 tailnet 地址打开 ybrain Web 界面（4096），可正常对话；
- [ ] A3 公网扫描确认 4096/8787 端口不可达（只绑 Tailscale 网卡）；22 与 8080/UDP 3478、41641 可达。

**B. 捕获**
- [ ] B1 Mac 浏览器扩展点一次，普通文章正文完整（标题/作者/正文）10 秒内出现在 `0-Inbox/`；
- [ ] B2 同一流程对微信公众号文章（浏览器打开后）正文完整；
- [ ] B3 Android 系统分享一段纯文字到 HTTP Shortcuts，10 秒内出现在收件箱（type: note）；
- [ ] B4 Android 分享一个链接，服务器抓到正文或落"仅链接"笔记（不丢内容）；
- [ ] B5 断网时扩展捕获 → 本地排队 → 恢复网络后自动补发成功，角标清零。

**C. 自动提炼**
- [ ] C1 新内容进入收件箱后，串行队列几分钟内完成：一句话摘要、3–5 标签、要点、PARA 归类移动、原文保留；
- [ ] C2 提炼后笔记从 `0-Inbox/` 移入对应 PARA 文件夹，frontmatter 状态为 distilled；
- [ ] C3 提炼结果自动 Git 提交并推送到 Gitee 私有仓库；
- [ ] C4 人为停掉服务期间捕获的内容，服务恢复后补提炼（不丢、不重复）；
- [ ] C5 提炼失败重试 3 次后在收件箱标红，不影响其他内容处理。

**D. 问答**
- [ ] D1 Web 界面提问，答案基于已捕获内容，并给出笔记标题与出处（链接或路径）；
- [ ] D2 问知识库中没有的内容，代理明确回答"资料里没有可靠依据"，不编造；
- [ ] D3 归档（4-Archive）笔记在检索中仍能被命中和引用。

**E. Mac 浏览与备份**
- [ ] E1 Mac 上 Obsidian 打开 vault（经 Gitee 同步），能浏览全部笔记、PARA 结构正确；
- [ ] E2 按 [backup-plan.md](backup-plan.md) 七步恢复清单在干净环境完成恢复，reindex 后能检索到旧笔记；
- [ ] E3 周复盘会话每周日晚产出：本周新增概览、最近 Gitee 推送时间、dead 任务数。

**F. 资源稳定**
- [ ] F1 连续运行 72 小时，内存峰值不触发容器被杀（swap 兜底生效），磁盘日志轮转正常。

## 二、构建顺序（每步可独立验证）

| 序 | 任务 | 独立验证方式 |
| --- | --- | --- |
| 0 | 服务器初始化：Docker CE + compose、4G swap、fail2ban | 命令行验证 docker/swapon 就绪 |
| 1 | ybrain fork 工程骨架：`packages/ybrain/` 隔离改动、GitHub Actions→ACR 构建、compose 模板、`openspec/` 空目录初始化 | CI 出镜像、服务器能 pull 起空壳 |
| 2 | headscale 部署 + Mac/Android/服务器宿主三端入网 | A1–A3 |
| 3 | 捕获接口 `/capture`：令牌鉴权、落盘收件箱、URL 抓取兜底 | curl 模拟三渠道请求，收件箱出现笔记 |
| 4 | 浏览器扩展（MV3）：Readability 提取、预览发送、失败队列 | B1、B2、B5 |
| 5 | Android HTTP Shortcuts 配置（出配置文档） | B3、B4 |
| 6 | 数据层：frontmatter 读写、SQLite + sqlite-vec、bge-m3 嵌入、重排 | reindex 命令对示例库跑通（复用票据 11 原型逻辑） |
| 7 | 四个原生知识工具注册（search/get/list_inbox/save_note） | 代理会话能调用工具检索 |
| 8 | 提炼队列与调度：jobs 状态机、进程内 distiller 会话、周复盘 | C1–C5、E3 |
| 9 | Git 自动提交 + Gitee 推送 | C3、E1 |
| 10 | 端到端验收 + 恢复演练 | 清单 A–F 全勾 |

依赖关系：0→1；1→2、3；3→6；6→7→8；3→4、5；8→9；全部→10。

## 三、明确不做（MVP 边界外）

- 微信读书同步（票据 15，MVP 后第一个增量）；
- 企业微信捕获/推送、每日简报推送渠道（雾区）；
- PDF/电子书/长文档解析；
- 登录与多用户、限流；
- Memos 等额外笔记服务、反向代理/域名/TLS；
- 存量历史资料迁移（单独雾区，MVP 后）；
- 本地模型、任何重量级 RAG 平台；
- 自我改进回路完整启用（票据 27，MVP 后第二个增量；MVP 只预留 `openspec/` 空目录 + feedback 识别指令）。
