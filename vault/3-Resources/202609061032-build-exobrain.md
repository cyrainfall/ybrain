# 如何构建一个外脑（ExoBrain）

## 要点

- **外脑的两层结构**：数字扩展记忆负责"记住且能找回"，扩展智力（大语言模型）负责"在自己的资料上推理综合"。与本项目架构直接对应：vault + 向量索引是记忆，ybrain 代理是智力。
- **捕获是唯一咽喉**：存一条信息超过十秒就不会存。→ 对三渠道（剪藏/安卓/读书）的验收标准：两次点击内完成。
- **提炼 ≠ 摘要**：摘要是压缩，提炼是连接——主动关联旧笔记、标注能支撑哪个项目。[[2026090614-wyckoff-spring-and-distillation]]：交易复盘同理，单点结论没有价值，连接到仓位纪律才有价值。
- **存档观**：归档不是"以后翻"，而是"敢放手"——移出日常视野，靠语义检索唤醒。

# 如何构建一个外脑（ExoBrain）

我把外脑分成两个部分：数字扩展记忆和扩展智力。数字扩展记忆解决的是"记住"的问题——你看过的东西不会消失，并且能在需要时被找回来；扩展智力解决的是"想起来"的问题——以大语言模型为引擎，在你自己的资料库上推理、综合、回答问题。

捕获是整个系统唯一的咽喉。如果一条信息要花超过十秒才能存下来，你就不会存。我的捕获入口有三个：浏览器剪藏、手机速记、读书笔记。三条路最终都汇到同一个收件箱……

PARA 不是分类法而是行动法。项目是有截止日期的努力，领域是长期的责任，资源是待用的素材，而存档是时间胶囊——大多数人误以为归档是为了"以后翻"，其实归档是为了"敢放手"：把不活跃的内容移出视野，同时知道检索能随时把它唤醒。

提炼不是摘要。摘要是压缩，提炼是连接：这篇内容和你已有的哪条知识相关？它能支撑你哪个项目？好的提炼会主动建立笔记之间的链接……
